HabitAlgo

HabitAlgo is an offline-first Progressive Web App (PWA) for personal habit tracking. Built with MERN + TypeScript, it offers a fast, reliable, and installable experience with advanced analytics and offline capabilities.

Features

Track boolean & numeric habits with streak calculation

Smart Calendar & daily check-ins

Offline-first: works without internet, auto-sync when online

PWA installable: mobile & desktop, app-like experience

Advanced features: Focus Mode, Daily Reflection, Screen Time Tracking, Dark Mode, Habit “Why” & Identity statements

Tech Stack

Frontend: React 18, TypeScript, Tailwind CSS, Zustand, TanStack Query, Dexie.js

Backend: Node.js, Express.js, MongoDB Atlas, Mongoose

PWA & Offline: Workbox, IndexedDB
